# ing — переводчик русский → ингушский

### 🌐 [Открыть переводчик](https://etrofimovv.github.io/ing/)

Нейросетевой переводчик на базе **NLLB-200 (3.3B)** с дообучением на
русско-ингушском параллельном корпусе.

**Как это устроено.** Страница по ссылке выше — только интерфейс.
Сам перевод выполняет программа на вашем компьютере (или на компьютере
коллеги в вашей сети). Текст не уходит в интернет и не попадает
на сторонние серверы.

> Если сервер перевода не запущен, страница так и напишет и подскажет,
> что делать. Инструкция ниже.

```
У него большой камень.  →  Йоккха кхера ба цун.
Здравствуйте!           →  Марша дахалда!
```

> ⚠️ **В этом репозитории только код.** Файлы модели (~13 ГБ) хранятся
> отдельно — см. раздел [Модель](#модель).

---

## Что это

Ингушский — нахский язык с **грамматическими классами**: прилагательные и
глагольные связки согласуются с классом существительного (б / д / в / й).
Это главная трудность машинного перевода на ингушский, и именно на неё
нацелено дообучение.

| метрика (dev 400) | значение |
|---|---|
| BLEU | 10.10 |
| chrF++ | 34.40 |
| точность класса (macro) | 56.1 % |
| корректная связка | 84 % |

Направление **ru → inh**. Обратное отключено: качество недостаточное.

## Установка

### Windows

```
git clone https://github.com/etrofimovv/ing.git
cd ing
```

Положите файлы модели (см. ниже), затем двойной клик по **`УСТАНОВКА.bat`**.

Установщик сам определит видеокарту и поставит нужную сборку PyTorch.

### Linux / macOS

```bash
git clone https://github.com/etrofimovv/ing.git
cd ing
python3.12 -m venv .venv
source .venv/bin/activate

# с видеокартой NVIDIA:
pip install torch --index-url https://download.pytorch.org/whl/cu124
# без неё:
pip install torch

pip install -r serve/requirements.txt
cp .env.example .env
python serve/selftest.py
```

## Модель

Веса в репозиторий не входят. Нужны три компонента:

```
ing/
├── models/
│   ├── v10-v6base-fixed/        база NLLB-200 3.3B  (~12 ГБ)
│   └── v19-case-fixed/final/    адаптер LoRA F19    (~681 МБ)
└── tokenizers/
    └── nllb-200-rus-inh-v6/     токенизатор с ингушским
```

Адаптер обучен поверх базы с расширенным токенизатором — **работает только
с ней**, к стандартному `facebook/nllb-200-3.3B` не подходит.

Ссылки на скачивание — в [Releases](../../releases) либо у автора.

## Сайт-интерфейс

Страница [etrofimovv.github.io/ing](https://etrofimovv.github.io/ing/)
работает как витрина: она не содержит модель, а обращается к вашему
серверу. Файл страницы — `index.html` в корне репозитория,
публикуется через GitHub Pages (workflow `.github/workflows/pages.yml`).

Чтобы страница заработала в локальной сети:

1. запустите `ЗАПУСТИТЬ_СЕРВЕР_API.bat` на компьютере с моделью;
2. откройте страницу — она сама найдёт сервер на `http://127.0.0.1:8080`;
3. если сервер на другом компьютере, впишите его адрес в поле на странице.

Браузер разрешает такие запросы только сайтам из списка
`ING_CORS_ORIGINS` в `.env` (по умолчанию — GitHub Pages автора
и localhost).

### Доступ через интернет

Если коллеги не в вашей сети, запустите `ДОСТУП_ИЗ_ИНТЕРНЕТА.bat`
(`tunnel_keepalive.py`). Скрипт поднимает туннель `localhost.run`,
записывает адрес в `api.json` и пушит его в репозиторий. Ссылка для
коллег при этом **не меняется** — всегда `etrofimovv.github.io/ing/`,
слать её нужно **без** `?api=`.

Две детали, без которых схема ломается (см. историю в `0_istina.md`, §71.10):

- Страница читает адрес не из `api.json` рядом с собой, а с
  `raw.githubusercontent.com` — CDN GitHub Pages кеширует файл на
  десятки минут, и после ротации туннеля связь пропадала.
- Адрес коммитится **только при реальной смене**. Туннель обрывается
  каждые ~20 минут; если пушить каждую ротацию, новая сборка Pages
  отменяет предыдущую и деплой не завершается никогда.

Порт задаётся через `ING_API_PORT` (по умолчанию 8080).

## Режим «одна машина считает, остальные подключаются»

Модель большая — ставить её на каждый ПК не нужно.

**На машине с видеокартой**, в `.env`:

```ini
ING_HOST=0.0.0.0
```

затем `ЗАПУСТИТЬ_СЕРВЕР_API.bat` — он покажет адреса вида `http://192.168.1.50:8080`.

**На остальных ПК** папку `models/` копировать не нужно, в `.env`:

```ini
ING_MODE=remote
ING_API_URL=http://192.168.1.50:8080
```

Такой клиент стартует за секунды.

## Настройки — `.env`

Скопируйте `.env.example` в `.env`.

| параметр | назначение | по умолчанию |
|---|---|---|
| `ING_ROOT` | путь к папке с моделями | рядом с `serve/` |
| `ING_MODE` | `local` / `remote` | `local` |
| `ING_API_URL` | адрес сервера для `remote` | — |
| `ING_API_TOKEN` | Bearer-токен доступа к API | пусто (без проверки) |
| `ING_DEVICE` | `auto` / `cuda` / `cpu` | `auto` |
| `ING_DTYPE` | `float16` / `bfloat16` / `float32` | `float16` |
| `ING_UI_PORT` | порт интерфейса | `7860` |
| `ING_API_PORT` | порт API | `8080` |
| `ING_HOST` | `127.0.0.1` локально, `0.0.0.0` для сети | `127.0.0.1` |
| `ING_CORS_ORIGINS` | сайты, которым разрешён доступ из браузера | GitHub Pages + localhost |
| `ING_NUM_BEAMS` | ширина beam search | `4` |

На CPU `float16` игнорируется — используется `float32`.

## HTTP API

```bash
curl -X POST http://127.0.0.1:8080/v1/translate \
  -H "Content-Type: application/json" \
  -d '{"text":"Это большой дом.","direction":"ru2inh"}'
```

```json
{
  "translation": "Из йоккха цӏа да.",
  "model_id": "f19_final",
  "latency_ms": 512.3,
  "device": "cuda"
}
```

| эндпоинт | назначение |
|---|---|
| `GET /health` | состояние, устройство, загруженная модель |
| `GET /v1/models` | список моделей |
| `POST /v1/translate` | перевод одной строки |
| `POST /v1/translate_batch` | пакетный перевод |

Если задан `ING_API_TOKEN`, все запросы требуют заголовок
`Authorization: Bearer <token>`.

## Ограничения

Модель **ошибается в классном префиксе примерно в половине случаев**:

| класс | точность |
|---|---|
| в | 100 % |
| й | 55 % |
| д | 39 % |
| **б** | **31 %** |

```
У него большой камень.  →  Йоккха кхера ба цун.
                           ^^^^^^          ^^
                     нужно «Боккха»    связка верна
```

Связка ставится верно чаще, потому что к этому моменту существительное уже
«видно»; префикс идёт перед словом — и здесь ошибок больше.

**Вывод:** пригодно как черновик и вспомогательный инструмент, требует
вычитки носителем языка. Особенно проверяйте прилагательные.

Другие ограничения: только ru → inh; длинные и терминологические тексты
переводятся хуже бытовых фраз.

## Устройство проекта

```
serve/
├── app/
│   ├── engine.py       загрузка модели, инференс
│   ├── ui_simple.py    веб-интерфейс (FastAPI)
│   ├── api.py          HTTP API
│   ├── remote.py       клиент удалённого API
│   └── envcfg.py       чтение .env поверх YAML
├── configs/
│   ├── serve.yaml           параметры запуска
│   └── models_registry.yaml реестр моделей
├── requirements.txt
└── selftest.py         самопроверка после установки
```

PyTorch намеренно не указан в `requirements.txt`: иначе pip перезапишет
CUDA-сборку на CPU-версию и перевод замедлится в десятки раз.
